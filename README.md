# Бурсач

Приложение для лабораторных и расчётных работ курсанта: дисциплины, работы, вводные данные, расчёт, отчёт Word.

Сайт: https://ВАШ-ЛОГИН.github.io/bursach/

Файлы:
- index.html — само приложение
- nav_assets.json — фото методички и карты 62028 (подгружаются в разделе «Методичка и карта»)
- manifest.json, icon-*.png — иконка, чтобы добавить сайт на экран «Домой» на айфоне
- .nojekyll — служебный файл для GitHub Pages
